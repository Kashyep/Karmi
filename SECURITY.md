# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub's private vulnerability reporting:

https://github.com/Ruud-en-Blauw/Karmi/security/advisories/new

Include what you found, the steps to reproduce it, and the version or commit you tested.
Do not include real personal data, sign-in codes, or live credentials in the report.

There is no response-time commitment. Reports are read by the maintainer, who will reply
through the advisory.

## Supported versions

Only the latest `main` branch and the current beta build are considered for fixes.

## Scope notes

- Never test against a hosted deployment you do not own, and never attempt to access another
  person's data.
- Do not run denial-of-service or load tests against the hosted beta.
