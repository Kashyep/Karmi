# MOB-003: Representative Screen (Phase 3)

**Status**: Implemented; T3.3 owner sign-off pending
**Owner**: Boss (integration)
**Plan**: `docs/UI_IMPLEMENTATION_PLAN.md` §6.1, §7 Phase 3

## Objective
Build the chat shell and representative screen as a proving ground for the core UI.

## Tasks
- [x] **T3.1**: `lib/shell/karmi_shell.dart`: `GlassScaffold` + `GlassAppBar` (overflow menu, Material since MOB-014:
  Plans, Licences) + `GlassTabBar.bottom` with Chat, Tasks, Usage, Memory, Settings. The glass bars'
  extent is passed to the body as `MediaQuery.padding` so content scrolls behind them. The tab
  bar's bar-level gesture node had no label (fails `labeledTapTargetGuideline`); it is wrapped in a
  labelled "Main navigation" container. Tasks placeholder replaced by the real screen (MOB-009).
- [x] **T3.2**: `lib/features/chat/` split into `chat_screen.dart`, `message_bubble.dart`,
  `composer.dart`, `status_chip.dart`, plus the local `chat_entry.dart` model (`UserEntry` keeps its
  idempotency key for retries; `ReplyEntry` wraps `MessageView`). States: empty (Trykker
  `EmptyState`), pending (`KarmiLoader` only while the request is in flight; static icon + text
  under reduced motion), each `Outcome` → Design.md copy (Completed, Corrected, Needs review,
  Awaiting confirmation, Could not confirm completion, Deferred, Status unknown), failed, offline,
  409 in-flight, 429 limit-reached (with reset time and "View plans"), 401 → Welcome. Errors use
  `ErrorBanner`; raw exception text is never shown. `StatusChip` = icon + word; text is always
  `--foreground` on `--muted`, tone colours only on icon/outline (all ≥4.5:1). Bubbles capped at
  38em of 16px body (~70 chars/line, scales with text size). Latest reply is a live region. Send
  control is a 48dp Material `IconButton.filled` inside the glass tray (not a glass button, to avoid
  glass-in-glass nesting). `ASK_USER` replies open the confirmation sheet (MOB-011).
- [ ] **T3.3**: Owner sign-off on screenshots (goldens in `mobile/test/goldens/`) — waiting on owner.
