## Contract

### features.py
- `estimate_tokens(text: str) -> int`: `max(1, len(text.encode("utf-8")) // 4)` (same method as
  `services.ContextManifest.counting_method`).
- `classify_task_domain(text: str) -> str`: deterministic, casefolded keyword rules returning one
  of `models.TASK_DOMAINS`. Precedence: reminder ("remind me", "reminder") > task ("to-do",
  "todo", "task", "add to my list") > memory_store ("note that", "save this", "remember that") >
  memory_query ("my notes", "what did i", "do you remember", "recall", text starting with
  "remember") > draft ("draft", "write", "rewrite", "compose", "email", "reply") > general.
  Only the label leaves this function.
- `build_routing_context(*, request_id, run_id, text, tier, context_budget_tokens,
  conversation_depth=0, retry_number=0, previous_tool_failure=False,
  previous_structured_output_failure=False, latency_slo_ms=None) -> RoutingContext`
  - `estimated_input_tokens = estimate_tokens(text)`;
    `context_utilization_ratio = min(1.0, estimated_input_tokens / context_budget_tokens)`
    (0.0 when budget ≤ 0).
  - The v1 API has no request-level tool/structured-output declaration, so
    `requires_tools=False`, `requires_structured_output=False`, `tool_count=0`,
    `requires_external_data=False`; `requires_memory = task_domain == "memory_query"`.
    Say so in a comment; the domain one-hot carries the soft signal.
  - Unknown tier → `ValueError` (callers fall back to static).
- `feature_vector(context) -> tuple[float, ...]` ordered exactly as `FEATURE_NAMES_V1`:
  bias=1.0; domain one-hot; `input_tokens_log = min(1, log1p(tokens)/log1p(32000))`;
  `context_utilization` clamped [0,1]; `tool_count_norm = min(tool_count,4)/4`; booleans 0/1;
  `conversation_depth_norm = min(depth,20)/20`; `tier_level_norm = TIERS.index(tier)/3`;
  `retry_number_norm = min(retry,3)/3`; `latency_slo_tight = 1.0 if slo is not None and slo <= 2000`.
  All values finite in [0, 1]. Raise `ValueError` if `context.feature_schema_version` differs.
- `named_features(context) -> dict[str, float]` (zip of names and vector).
- Pure functions: no globals, no I/O, no clock.

### eligibility.py
- `REASON_CODES` tuple: `tier_not_entitled`, `bundle_tier_restriction`, `model_disabled`,
  `live_models_disabled`, `context_capacity`, `tools_unsupported`,
  `structured_output_unsupported`, `provider_unhealthy`, `request_budget`, `period_budget`.
- `filter_eligible(context, candidates, *, plan: PlanPolicy, disabled_models: Collection[str],
  live_models_enabled: bool, tier_restrictions: Mapping[str, Collection[str]] | None = None)
  -> EligibilityResult`
  - Collect *all* failing reasons per candidate (sorted tuple) in `rejections`; eligible keeps
    input order.
  - tier: `context.tier not in candidate.entitled_tiers`; restriction: model present in
    `tier_restrictions` and tier not in its list (narrowing only).
  - context: `estimated_input_tokens + context_budget_tokens > max_context_tokens`.
  - tools/structured: only when the context requires them.
  - cost: `candidate.expected_cost_micro(estimated_input_tokens + context_budget_tokens)`
    `> plan.request_cost_cap_micro` → `request_budget`; `> plan.period_cost_cap_micro` →
    `period_budget`.
- `require_eligible(result) -> EligibilityResult`: raises `NoEligibleModel(rejections)` when empty.

### static_policy.py
- `STATIC_POLICY_VERSION = "static-v1"`. `StaticRoutingPolicy(preference=(LIVE_ROUTE, LOCAL_ROUTE))`.
- `select`: first preferred route present in candidates, else smallest model id; probability 1.0,
  `exploration=False`, `algorithm="static"`, `action_probabilities` covering every candidate in
  candidate order (1.0 selected, 0.0 others). Empty candidates → `PolicyError`.
- Parity: with live models enabled and the live route eligible it selects `typesafe-system-one`;
  otherwise `fake-economy` — exactly the baseline behaviour.

### bandit_policy.py
- `ExplorationConfig(rate_for: Callable[[RoutingContext], float], max_cost_micro: int)`
  (frozen dataclass). `rate_for` returns the ε allowed for that context (0 disables).
- `BanditRoutingPolicy(params: LinUCBPolicyV1, *, policy_version: str,
  exploration: ExplorationConfig | None = None, rng: random.Random | None = None)`.
  Constructor raises `PolicyError` if `params.feature_schema_version != FEATURE_SCHEMA_VERSION`
  or `params.dimension != len(FEATURE_NAMES_V1)`.
- `select`: x = `features.feature_vector(context)`; greedy g = `scoring.greedy_model(params,
  candidate ids, x)` (models without an arm are unscoreable). None → `PolicyError`.
  ε = clamp(rate_for(context), 0, 1) (0 when no exploration config). Explore set E = candidates
  that have an arm and `expected_cost_micro(estimated_input_tokens + context_budget_tokens)
  <= max_cost_micro`. If E empty, ε = 0.
  p(a) = (1-ε)·[a==g] + ε·[a∈E]/|E| for every candidate (0 for unscoreable).
  Draw `u = rng.random()`; `exploration = u < ε`; exploring → uniform choice from sorted E via
  `rng`; else g. `selection_probability = p(selected)` exactly. `algorithm="linucb"`.
  Any non-finite score or internal error → `PolicyError`. Never mutates params (no training).
- Default rng: `random.SystemRandom()`.

### shadow_policy.py
- `ShadowRoutingPolicy(live: RoutingPolicy, shadow: RoutingPolicy)`; `policy_version` = live's;
  `select` returns the live decision; `select_both(context, candidates) ->
  tuple[RoutingDecision, RoutingDecision | None, str | None]` where a shadow exception is caught
  and returned as an identifier string `shadow_<ExceptionClassName>` (the live decision must
  never be affected; live exceptions propagate).

## Acceptance
- Golden tests: identical fixtures → identical feature vectors; domain precedence table; vector
  length/order/range; unknown tier rejected.
- Eligibility unit tests for every reason code, multiple reasons collected, narrowing-only
  restrictions.
- Property-style test (stdlib `random` with fixed seeds, ≥ 500 cases, no new dependency):
  random contexts × random eligible subsets × adversarial LinUCB params (huge, negative, zero
  weights, arms for unknown models, missing arms) → the returned model is always in the
  candidate set, probabilities sum to 1 (±1e-9), `selection_probability` equals
  `dict(action_probabilities)[selected]`, and ε exploration never selects outside E.
- Static parity table: (live enabled × live healthy × tier) → expected baseline route.
- Shadow exception isolation test.
- `python -m ruff check src tests`, `python -m mypy src`, `python -m pytest tests/unit/routing -q`
  pass. Do not run or modify other suites; do not commit.
- Report: files, test count, any contract gaps found.
