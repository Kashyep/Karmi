## Contract
- Tiers: 1 ananta "Ananta", 2 yanta "Yanta", 3 trika "Trika", 4 parth "Parth". `PLAN_LABELS`
  becomes ("Ananta", "Yanta", "Trika", "Parth"). never with a double k.
- Armory API (API-002): `GET /v1/armory` → `{unlocked_tier, active_theme, tiers:[{id,key,label,plan_id}]}`;
  `PUT /v1/armory/active-theme {active_theme}` → same view, 403 `detail.code == "TIER_LOCKED"`, 422 invalid.
- `<html data-tier="ananta" data-theme="light">`; all colours come from CSS custom properties in
  `karmi-tokens.css` (`--color-background`, `--color-foreground`, `--color-card`, `--color-primary`,
  `--color-primary-foreground`, `--color-primary-text`, `--color-muted`, `--color-muted-foreground`,
  `--color-border`, `--color-ring`, `--color-glass-base`, `--color-glass-border`,
  `--color-glass-highlight`, `--color-glass-fallback`, …). No hard-coded hex left in `_STYLES`.
- Theme mode: System / Light / Dark control, persisted in `localStorage`, "System" follows
  `matchMedia('(prefers-color-scheme: dark)')` live. Switching only changes the two attributes (O(1)).
- `.glass-panel`: `backdrop-filter: blur(16px)`, `var(--color-glass-base)`, 1px `var(--color-glass-border)`
  border, top highlight, hover/active states; `@supports not (backdrop-filter: blur(16px))` → opaque
  `--color-glass-fallback`; `prefers-reduced-transparency: reduce` and `forced-colors` also opaque.
  Glass only on the topbar, the composer tray and the Armory preview banner — content cards stay opaque.
- Armory section `#armory` (nav link "Armory"): 4 cards from a config array; tier > unlocked →
  `filter: blur(4px) grayscale(80%)` on the card's visual, padlock, activation disabled
  (`aria-disabled`, not clickable), "Preview 10 s" button. Preview sets `data-tier` locally for 10 s
  then reverts; a new preview/activation/unload cancels the old timer; visible countdown with
  "End preview"; announced via `aria-live`. Activate unlocked tiers via PUT; on 403 re-fetch.
- PWA: `/manifest.webmanifest?tier=<key>` returns name "Karmi", tier `theme_color`/`background_color`
  and the tier's icons (192/512 PNG + 512 WebP); unknown tier → ananta. The page updates
  `<link rel="manifest">` and `<meta name="theme-color">` when the effective tier changes; the Armory
  explains that an installed PWA keeps its icon until reinstalled (browsers cannot change it).
- Focus: 2px `--color-ring` outline (3px under `prefers-contrast: more`) on every control.
