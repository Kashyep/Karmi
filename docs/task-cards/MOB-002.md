# MOB-002: Mobile Client Foundation (Phase 2)

**Status**: Done
**Owner**: Boss (integration)
**Plan**: `docs/UI_IMPLEMENTATION_PLAN.md` §2, §5, §7 Phase 2

## Objective
Establish the theme, glass treatments, motion settings, and API client for the new Flutter mobile app.

## Tasks
- [x] **T2.1**: `lib/theme/karmi_colors.dart` (ThemeExtension, §2.2–2.3 plus Design.md success/warning)
  and `lib/theme/karmi_theme.dart` (ColorScheme, §3.5 TextTheme, `KarmiText`, `KarmiShape`).
  Dark `borderSubtle` is now the derived `129 26% 18%` = `#223a26` (was transparent); decorative
  only, 1.51:1 on the dark background (light `borderSubtle` is 1.22:1).
- [x] **T2.2**: `lib/app.dart` wires `LiquidGlassWidgets.wrap` (both `GlassThemeData` variants,
  `brightnessResolver: Theme.maybeBrightnessOf`), the transparency `Material` builder and
  `GlassAccessibilityScope`. `lib/theme/karmi_glass.dart`: tint floor 0.72 light / 0.78 dark from
  `--card`; `KarmiGlassSurface` becomes an opaque `--card` + 1px `--border` surface under reduce
  transparency or platform high contrast. Glass is used only on the §5.1 surfaces (app bar, tab bar,
  composer tray, settings header, overflow menu); notes, usage, settings content, tasks, plans and
  banners are opaque `KarmiCard`s. With reduce transparency on, the shell swaps to opaque Material
  `AppBar` + `NavigationBar`.
- [x] **T2.3**: `lib/theme/karmi_motion.dart` (`KarmiAccessibility`, `KarmiMotion`: 120/180ms, or
  `Duration.zero` under reduced motion; `KarmiMotion.route`). Reduce transparency persisted in
  `lib/settings/karmi_settings.dart`. High contrast: `highContrastTheme`/`highContrastDarkTheme` set
  every border to `--foreground` and focus rings to 3px (2px otherwise).
- [x] **T2.4**: `lib/api/` — `KarmiApi` (base URL from `--dart-define=API_BASE_URL`, default
  `http://10.0.2.2:8000`), `issueDevToken` (`POST /dev/token`), messages, usage, notes
  (list/create/delete, `NoteView.version`), tasks (list/complete). Typed errors: `Unauthorized`
  (401), `InFlight` (409 "in flight"), `IdempotencyConflict` (409 payload mismatch),
  `LimitReached` (429 `detail.code == "ALLOWANCE_EXHAUSTED"`, `detail.reset_at`, from
  `api.py send_message`/`services.BudgetDenied`), `Network` (SocketException, ClientException,
  timeout), `Server`. `Outcome` members are lowerCamel with wire names; unknown values parse to
  `Outcome.unknown`. `'dev_mock_token_placeholder'` removed; token comes from `KarmiSession`.
