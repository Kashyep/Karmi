## pseudonym.py
- `telemetry_key(auth_secret: str) -> bytes` = HMAC-SHA256(auth_secret, b"karmi-telemetry-pseudonym-v1").
- `actor_id(key, account_id, user_id) -> str` (hex HMAC of `"actor:{account}:{user}"`),
  `request_fingerprint(key, text) -> str` (HMAC of casefolded, whitespace-collapsed text),
  `value_hash(key, text) -> str`. All 64-char lowercase hex.

## sanitizer.py
- High-risk classes (constants): `email`, `phone`, `api_key` (e.g. `sk-…`, `sk_live_…`, `AKIA…`,
  `ghp_/gho_/github_pat_`, `xox[abpr]-`, `AIza…`), `bearer_token` / `jwt`, `private_key` block,
  `card_number` (Luhn-checked 13–19 digits), `secret_assignment` (`password=`, `token:`, `secret=`,
  `api_key=` …), `aadhaar` (12 digits in 4-4-4 groups), `pan` (`[A-Z]{5}[0-9]{4}[A-Z]`),
  `street_address` (house number + street word + suffix such as Street/St/Road/Rd/Avenue/Ave/
  Lane/Marg/Nagar), `high_entropy_token` (≥ 32 chars of `[A-Za-z0-9+/_=-]` with mixed classes).
- `scan(text) -> frozenset[str]`, `redact(text) -> tuple[str, frozenset[str]]` replacing matches
  with `[REDACTED:<class>]`.
- `sanitize_free_text(text, *, max_length=2000) -> str | None`: redact, re-scan the result; if any
  high-risk class remains, return `None` (fail closed); else truncate to `max_length`.
- `validate_export(payload: object) -> None`: walk parsed JSON; scan every string value except
  values under keys known to be ids/hashes/timestamps/versions (`*_id`, `*_hash`, `*_at`,
  `*_version`, `batch_id`, `payload_sha256`, `anonymous_actor_id`) and dict keys that are feature
  names/model ids; raise `SanitizationError(classes, path)` on any finding. A realistic batch of
  generated runs must pass (no false positives on uuids, hex digests, model ids, versions).

## collector.py
- `TelemetrySink` Protocol: `emit(event) -> None`, `start()`, `stop(timeout: float = 5.0)`,
  `flush(timeout: float = 5.0) -> bool`, `health() -> dict[str, object]`.
- `NullCollector` (telemetry disabled): all no-ops; `health()` reports `enabled: False`.
- `TelemetryCollector(*, session_factory: Callable[[], Session], queue_size, batch_size,
  flush_interval_seconds, spool_path: Path, attribution_window_seconds: int,
  finalize_interval_seconds: float = 30.0, metrics: Metrics = METRICS,
  clock: Callable[[], datetime] = utcnow)`.
  - `emit` never raises and never touches the DB. Optional events (`priority_of`) are dropped when
    the queue is ≥ 80 % full (`telemetry_dropped_optional_total`). Mandatory events use
    `put_nowait`; on `queue.Full` they are appended to the JSONL spool (thread-safe, one
    `model_dump_json` per line) — `telemetry_spooled_total`. Never block the caller.
  - One daemon writer thread: drains up to `batch_size` events or waits `flush_interval_seconds`,
    writes via `writer.persist_events(session, events, now)` in one transaction; on DB error:
    rollback, `telemetry_write_failures_total`, exponential backoff (cap 30 s), keep the batch in
    memory (bounded by batch_size) and retry; if `stop()` happens while failing, spool the batch.
  - Spool replay: on `start()` and after every successful write when the spool is non-empty,
    atomically rename the spool to a `.replaying` file, parse lines with the `TelemetryEvent`
    discriminated union, persist, delete the file; unparsable lines go to `<spool>.rejected`
    (counted, never crash).
  - Every `finalize_interval_seconds` the writer runs `finalizer.finalize_due(...)`.
  - Gauges: `telemetry_queue_depth`, `telemetry_last_flush_ms`, `telemetry_oldest_unwritten_age_s`.
  - `flush(timeout)` waits until everything emitted before the call is persisted (or spooled);
    `stop(timeout)` flushes, stops the thread, spools anything left. Idempotent start/stop.

## writer.py
- `persist_events(session, events, *, now, attribution_window_seconds) -> None` (caller commits).
  Idempotent by primary key (replayed spools must not duplicate or fail): skip rows whose PK
  already exists.
  - `RunRecord` → `telemetry_runs` (JSON columns: `json.dumps(sort_keys=True, separators=(",", ":"))`),
    `telemetry_router_decisions`, `telemetry_model_attempts`, `telemetry_tool_events`,
    `telemetry_run_outcomes` (immediate fields, signal flags False, `finalized_at` NULL).
    Derived retry: if `request_fingerprint` is set and an earlier run by the same
    `anonymous_actor_id` with the same fingerprint completed within the attribution window before
    this run started, insert a `retry` signal (weak, confidence 0.6, derived) for the earlier run.
  - `SignalRecord` → `telemetry_outcome_signals`; `late=True` if the run already has
    `export_batch_id`. `FeedbackRecord` → `telemetry_feedback` (same `late` rule) **and** a
    matching strong explicit signal (`accept`→accept, `reject`→reject, `correction`→correction,
    `preference`→preference, `changed_intent`→changed_intent, confidence 1.0).
  - `OpsEventRecord` → `telemetry_ops_events`.

## finalizer.py (OutcomeFinalizer)
- `finalize_due(session, *, now, window_seconds, limit=500) -> int`: runs whose outcome row has
  `finalized_at IS NULL` and `completed_at <= now - window` (compute cutoff in Python). Aggregate
  signals → `user_retry_signal`, `user_accept_signal`, `user_correction_signal`,
  `correction_distance` (latest correction feedback with a distance), `user_abandon_signal`
  (only when the run outcome is `ASK_USER` and the same actor has no later run within the
  window: also insert a weak derived `no_followup_after_ask` signal, confidence 0.3). Set
  `finalized_at = now`. Never infer failure from an edit; store only categories.
- `finalize_run(session, run_id, *, now)` for tests/ops.

## exporter.py
- `export_batch(session, *, out_dir: Path, producer_version: str, now, limit=1000) ->
  ExportResult | None` where `ExportResult(batch_id, path, run_count, signal_count,
  feedback_count, payload_sha256)`.
  - Runs: finalized, `export_batch_id IS NULL`, ordered `(completed_at, run_id)`, up to `limit`,
    each with its decisions/attempts/tool events/final outcome/signals/feedback as
    `ExportedRunV1`. `request_fingerprint` is never exported.
  - Late items: signals/feedback with `late=True` and no `export_batch_id`.
  - Nothing to export → `None`.
  - `batch_id` = sha256 hex of `"kashyep-karmi|"` + sorted run ids + sorted late signal ids + sorted
    late feedback ids (deterministic ⇒ retry after a crash rewrites the identical batch).
  - `payload_sha256` over canonical JSON (`sort_keys`, compact separators) of
    `{"runs","late_signals","late_feedback"}` in `mode="json"`.
  - Validate with `TelemetryBatchV1`, then `sanitizer.validate_export` (fail closed: raise, write
    nothing, mark nothing). Write `telemetry-batch-<batch_id>.json` via temp file + `os.replace`,
    plus `<file>.sha256` of the file bytes. Then mark exported rows and insert
    `telemetry_export_batches`; caller commits. Export never deletes anything.
  - Metrics: `telemetry_export_batches_total`, gauge `telemetry_oldest_unexported_age_s`.

## retention.py
- `purge_expired(session, *, now, retention_days) -> dict[str, int]`: delete telemetry rows older
  than the cutoff **only if exported** (runs + child rows by run id; signals/feedback with a
  batch id); ops events older than cutoff. Unexported rows are kept and counted.
- `purge_actor(session, anonymous_actor_id) -> dict[str, int]`: delete every telemetry row for that
  pseudonym (runs + children + signals + feedback + outcomes) regardless of export.

## __main__.py (CLI, `python -m daily_agent.telemetry`)

## Acceptance (tests in `tests/unit/telemetry/`, temp SQLite via `Base.metadata.create_all`)
- Sanitizer fixtures with emails, phone numbers (Indian and international), API keys, bearer/JWT,
  private key, card numbers, Aadhaar/PAN, street addresses, secrets, memory text: each class
  detected and redacted; residual high-risk → `None`; export validation rejects a batch with an
  injected secret and accepts a realistic clean batch.
- Collector: `emit` latency stays small with a stalled/unavailable DB (session factory that raises
  or sleeps); mandatory events spill to spool when queue is full, then replay into the DB once it
  recovers without duplicates; optional events dropped under pressure; memory bounded (queue
  size); `stop()` persists mandatory events; spool replay idempotent (replay twice → no dupes).
- Writer: all tables populated from a `RunRecord`; derived retry signal; late flags.
- Finalizer: window respected; signal aggregation; abandon only for `ASK_USER` without follow-up.
- Exporter: deterministic batch id and payload checksum across two exports of the same data
  (second call after un-marking or crash simulation); rows marked; `None` when empty; file
  validates against `TelemetryBatchV1`; late signals appear in a later batch.
- Retention: exported old rows deleted, unexported kept; `purge_actor` removes one actor only.
- `python -m ruff check src tests`, `python -m mypy src`, `python -m pytest tests/unit/telemetry -q`
  pass. Do not run or modify other suites; do not commit.
