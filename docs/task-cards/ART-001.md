## verifier.py
- `class BundleRejected(Exception)`: attributes `code: str` (stable identifier) and `detail: str`.
  Codes: `not_a_directory`, `symlink`, `unexpected_file`, `missing_file`, `file_too_large`,
  `bad_public_key`, `bad_signature`, `bad_checksums`, `checksum_mismatch`, `invalid_json`,
  `schema_invalid`, `feature_schema_mismatch`, `dimension_mismatch`, `unknown_model`,
  `arm_mismatch`, `tier_widening`, `karmi_too_old`, `harness_mismatch`, `self_test_failed`.
- `verify_bundle(path: Path, *, public_key_b64: str | None, known_models: Mapping[str,
  frozenset[str]], karmi_version: str, now: datetime) -> LoadedBundle`. Order:
  1. Path safety: `path` is a real directory (not a symlink); walk it with `os.walk(followlinks=False)`;
     any symlink/junction or path outside `REQUIRED_FILES | HARNESS_FILES` → reject; each file
     `<= MAX_FILE_BYTES` (check `stat` before reading).
  2. Required files present. Harness files present iff `manifest.harness_included` (checked after
     manifest parse; either both or neither).
  3. Signature: public key is base64 of 32 raw Ed25519 bytes (`None`/invalid → `bad_public_key`);
     `signature.sig` is base64; verify over the exact bytes of `checksums.json`.
  4. `ChecksumsV1`: listed files must equal present files minus `checksums.json`/`signature.sig`;
     every sha256 matches (`hmac.compare_digest`).
  5. Parse JSON strictly: UTF-8, `json.loads(..., parse_constant=<reject NaN/Infinity>)`,
     then the pydantic model for each file (`model_validate`, errors → `schema_invalid`).
  6. Compatibility: manifest/policy/feature-schema versions all equal `FEATURE_SCHEMA_VERSION`;
     `feature_schema.feature_names == list(FEATURE_NAMES_V1)`; `policy.dimension ==
     len(FEATURE_NAMES_V1)`; `set(policy.arms) == set(manifest.model_registry)` (`arm_mismatch`);
     each model id in `known_models` (`unknown_model`); `tier_restrictions` keys in
     `model_registry` and tiers ⊆ `known_models[model]` (`tier_widening`);
     `min_karmi_version <= karmi_version` (numeric tuple compare).
  7. Self-test: for each `self_test_cases` entry — vector length equals dimension, eligible models
     ⊆ arms, `scoring.greedy_model(policy, eligible, vector) == expected_model`; every score finite.
  8. Return `LoadedBundle(... content_sha256=sha256(checksums.json bytes), verified_at=now)`.
  Nothing outside `path` is read or written.

## store.py
- `PolicyStore(root: Path, *, public_key_b64: str | None, known_models, karmi_version,
  clock=utcnow, metrics=METRICS)`. Layout: `root/bundles/<artifact_version>/`, `root/state.json`.
- `PolicyState` (pydantic, `extra="forbid"`): `active`, `previous`, `last_known_good`, `shadow`
  (all `str | None`), `installed: list[str]`, `history: list[StateEvent]` (last 200;
  `StateEvent(action, version, at, reason)`), `revision: int`.
- `read_state() -> PolicyState` (missing file → empty state; corrupt → raise `StoreCorrupt`).
- `install(source: Path) -> LoadedBundle`: verify source; copy to a temp dir inside
  `root/bundles/`, re-verify the copy, `os.replace` into `bundles/<version>`. Re-installing the
  same version with identical `content_sha256` is a no-op; different content → `BundleRejected`
  (`version_conflict`). Adds to `installed` (history `install`). Does not change active/shadow.
- `load(version) -> LoadedBundle`: re-verify from disk every time (never trust disk).
- `set_shadow(version | None)`, `promote(version)` (requires installed + verifies +
  `evaluation.passed_regression`, else `BundleRejected("not_promotable")`; sets
  `previous = active`, `active = version`), `mark_known_good(version)` (must be installed and
  verify), `rollback(reason) -> str | None`: new active = `previous` if it still verifies, else
  `last_known_good` if it verifies (and differs from the failing active), else `None` (static);
  the rolled-back version is cleared from `shadow` too; one call, one state write.
  `deactivate(reason)` → active `None`.
- Every state write: serialise, write temp file in `root`, flush + `os.fsync`, `os.replace` onto
  `state.json` (atomic swap), increment `revision`. Guard mutations with a `threading.Lock`;
  document single-writer (CLI) assumption across processes.
- Metrics: `policy_verification_failures_total{code}`, `policy_rollbacks_total`, gauge-like
  counters for activation.

## __main__.py (CLI, `python -m daily_agent.policy_artifacts`)
- typer commands: `verify PATH`, `install PATH`, `shadow VERSION` / `shadow --clear`,
  `promote VERSION`, `mark-good VERSION`, `rollback --reason TEXT`, `deactivate --reason TEXT`,
  `status`. Build the store from `get_settings()` (`router_policy_dir`,
  `router_policy_public_key`), `routing.registry.entitlement_map()`, `daily_agent.__version__`.
  Exit code 1 with the rejection code on failure.

## tests/support/policy_bundles.py (shared with the Boss's e2e tests)
- `generate_keypair() -> tuple[Ed25519PrivateKey, str]` (private key, base64 public key).
- `write_bundle(dir: Path, *, private_key, version="test-1", arms: dict[str, LinUCBArm-like
  dict] | None = None, alpha=0.0, harness=False, passed_regression=True, mutate: Callable | None
  = None, ...) -> Path` building every file, correct `self_test_cases` (computed with
  `scoring.greedy_model`), checksums and signature. Default arms: `fake-economy` and
  `typesafe-system-one`, with `theta` making `fake-economy` win for the default self-test vector.
  Helpers to tamper after signing (e.g. rewrite a file, add a file, add a symlink when the OS allows).

## Acceptance (`tests/unit/policy_artifacts/`)
- Every rejection code has a test (symlink test skips cleanly where symlinks are unavailable).
- Tampered file after signing → `checksum_mismatch`; re-signed with another key → `bad_signature`;
  NaN in JSON → `invalid_json`; extra file → `unexpected_file`; wrong dimension; unknown model;
  widened tier; `min_karmi_version` too new; self-test disagreement; harness flag mismatch.
- Store: install idempotent; version conflict; promote requires regression pass; promote →
  rollback restores previous in one call; rollback falls back to last-known-good when previous is
  corrupted on disk; rollback to static when nothing verifies; state file remains valid JSON after
  every operation; a failed install leaves the active policy and state untouched.
- CLI smoke via `typer.testing.CliRunner` for `verify`, `install`, `promote`, `rollback`, `status`.
- `python -m ruff check src tests`, `python -m mypy src`,
  `python -m pytest tests/unit/policy_artifacts -q` pass. Do not run or modify other suites; do
  not commit.
- Report: files, test count, contract gaps found.
