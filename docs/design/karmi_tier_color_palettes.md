# Karmi: Application Tier Color Palettes

This document outlines the specific color palettes and UI application rules for the four tiers of the Karmi application. The app utilizes a glassmorphic design system, so these colors will interact with varying levels of transparency, blur, and lighting.

---

## Tier 1: Ananta (The Foundation)
**Vibe:** Organic growth, approachability, and foundational balance.

| Color | Hex Code | Usage Context |
| :--- | :--- | :--- |
| **Active Accent** | `#66C796` | Bright Mint Green. Used for primary calls-to-action (CTAs), progress bars, active icons, and glowing highlights in dark mode. |
| **Primary Base** | `#1E422C` | Deep Green. Used for primary app headers, solid structural blocks, and the app icon background. |
| **Light Background** | `#F2F7F4` | Mint White. The main canvas color for Light Mode, providing a soft, organic alternative to pure white. |
| **Dark Background**| `#0B1A11` | Near Black Green. The main canvas color for Dark Mode. Deep and rich to make the mint accents pop. |
| **Text/Structural** | `#050806` | Pure Dark. Used for high-contrast primary text in light mode and subtle structural borders. |

---

## Tier 2: Yanta (The Control)
**Vibe:** Precision, engineered focus, and structured capability.

| Color | Hex Code | Usage Context |
| :--- | :--- | :--- |
| **Active Accent** | `#00D4FF` | Electric Cyan. High-visibility color for primary buttons, active toggles, and the illuminated app icon symbol. |
| **Primary Base** | `#1A365D` | Cobalt/Navy. Used for secondary glass panels, navigation bars, and structural UI elements. |
| **Light Background** | `#F4F6F9` | Ice White. A crisp, cool-toned off-white canvas for Light Mode, feeling clinical and clean. |
| **Dark Background**| `#0A111C` | Deep Slate. A dark, desaturated navy canvas for Dark Mode, resembling a developer environment or terminal. |
| **Text/Structural** | `#8BA2C4` | Muted Indigo. Used for secondary text, faint grid patterns on backgrounds, and subtle glass borders. |

---

## Tier 3: Trika (The Trinity)
**Vibe:** High-velocity output, dynamism, and premium energy.

| Color | Hex Code | Usage Context |
| :--- | :--- | :--- |
| **Active Accent** | `#FF5722` | Sunset Orange / Ember. Used for primary actions, striking progress rings, and the glowing "heat" of the app icon. |
| **Primary Base** | `#8C3B20` | Terracotta. Deep, warm tones for solid panels, inactive states, and glass tinting. |
| **Light Background** | `#FCF8F5` | Warm Cream. A soft, warm-toned canvas for Light Mode to contrast with the aggressive orange accents. |
| **Dark Background**| `#171210` | Smoky Charcoal. A very dark, warm grey canvas for Dark Mode to make the ember accents glow dramatically. |
| **Text/Structural** | `#E0D4CD` | Ash. Used for secondary text and structural UI borders, providing a soft contrast against the dark background. |

---

## Tier 4: Parth (The Apex)
**Vibe:** Exclusive luxury, ultimate focus, and minimalist achievement.

| Color | Hex Code | Usage Context |
| :--- | :--- | :--- |
| **Primary Accent** | `#D4AF37` | Metallic Gold. The main status color. Used for core interactions, premium badges, and primary app icon elements. |
| **Secondary Accent**| `#9B4F96` | Iridescent Purple. Used for subtle gradients, secondary premium highlights, or glass refractions. |
| **Light Background** | `#FFFFFF` | Pure White. A stark, uncompromising white canvas for high-contrast minimalist luxury in Light Mode. |
| **Dark Background**| `#000000` | True Obsidian/Pitch Black. The ultimate dark mode canvas. Perfect for OLED screens, allowing the gold and purple to float seamlessly. |
| **Text/Structural** | `#1A1A1A` | Ultra Dark Grey. Used for almost-invisible translucent borders on glass panels and primary text in Light Mode. |

---
*Note: When applying these colors to a glassmorphic UI, utilize varying opacities (e.g., 10% to 40%) of the 'Primary Base' or 'Background' colors with background-blur effects to create frosted glass panels.*
